Este estudo de caso analisa dados de vendas da Amazon com o objetivo de identificar padrões de consumo, desempenho de categorias e oportunidades de melhoria estratégica.

---

### 🎯 Objetivo do Projeto

O objetivo principal é analisar o desempenho de vendas para responder perguntas de negócio como:

- Quais categorias vendem mais?
- Quais produtos geram maior receita?
- Existe sazonalidade nas vendas?
- Como a quantidade vendida impacta o faturamento?
- Há padrões mensais relevantes?

---

### 🧩 Contexto de Negócio

Uma empresa deseja entender melhor o comportamento de vendas na plataforma Amazon para:

- Otimizar o portfólio de produtos
- Melhorar estratégias de precificação
- Identificar categorias mais lucrativas
- Apoiar decisões estratégicas baseadas em dados

### 📊 Principais Métricas Analisadas

- Receita total  
- Quantidade vendida  
- Receita por categoria  
- Receita por produto  
- Tendência mensal de vendas  

---

### 📈 Principais Insights

- Identificação das categorias com maior volume de vendas  
- Produtos com maior geração de receita  
- Padrões sazonais no comportamento de compra  
- Relação entre quantidade vendida e faturamento  

---

### 💡 Conclusões

Este estudo permite compreender melhor o desempenho comercial e fornece recomendações estratégicas baseadas em dados reais.
